4. confirm_otp_token() takes login_manager object, NOT session string
5. get_2fa_method() does NOT exist — use frappe.twofactor.get_verification_method()

8. Frappe returns 403 (not 401) for session expiry
9. vite.config.ts uses fast-glob — do NOT manually add page entries
